# The ESF Rosetta Stone Map

An interactive evidence map for the Evolutionary Stress Framework (ESF): 50 sources organized across 6 evidence layers, mapped to 14 ESF claims and 13 cross-cutting tags.

**Live map:** https://lorihogenkamp-ops.github.io/esf-rosetta-map/

**Archived version (DOI):** [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23422797.svg)](https://doi.org/10.5281/zenodo.23422797)

## What it is

The map shows how findings from stress physiology, predictive processing, network medicine, developmental science, ecology, and neurodiversity scholarship relate to the core claims of the ESF. Each source is placed in an evidence layer and linked to the claims it supports, so the framework's evidence base can be inspected claim by claim.

## How to use it

Open the live link above. Filter by evidence layer, claim, or tag; click any source for its details and the claims it supports. The whole map is a single self-contained HTML file — download `index.html` to use it offline.
